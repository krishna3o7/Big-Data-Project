# Traffic Accident Data Processing - Web Project

Open `index.html` in VS Code. Recommended: install the VS Code Live Server extension,
then right-click `index.html` and choose "Open with Live Server".

Features:
- Interactive dashboard
- CSV upload and parsing
- Accident totals, vehicles and casualties
- Severity, weather, location and road-condition charts
- Dataset preview
- Apache Pig workflow display
- Downloadable Pig script

The website is the presentation/interaction layer. Apache Pig remains the data-processing
technology described in the project report.
